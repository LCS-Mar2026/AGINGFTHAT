AFT Biological Age Model

September 2026 · Working Model v1.0
MODEL PAGE — NO PERSONAL DATA STORED HERE

This page defines the multifactorial AFT Biological Age model itself: the markers included, the scoring bands, their relative weightings and the calculation logic. Personal results belong in the Personal Data / client record, not in this model specification.

How it works. Each available biomarker is converted to a score of 100, 75, 40 or 10 according to its current optimal/good/warning band. That score is multiplied by the marker weighting. Missing values are excluded rather than guessed, and the remaining weights are re-normalised automatically. The weighted composite is then translated into an estimated biological-age difference from chronological age. This is an AFT composite estimate, not an epigenetic clock or medical diagnosis.

Calculation logic

marker score ∈ {100, 75, 40, 10}\nweighted composite = Σ(marker score × marker weight) / Σ(weights of entered markers)\nbiological age = chronological age − ((weighted composite − 50) / 50 × 17)

The model therefore rewards a larger contribution from the markers with higher weights. The current scoring bands and weights below are the same ones used by the website calculator as at 4 September 2026.

Model governance

Before any future release is treated as locked, changes to marker inclusion, thresholds, weighting, directionality or age-translation logic should be versioned and date-stamped. Personal data should remain in Personal Data and client biometrics in the client bundle/dashboard.

This is a working AFT methodology tool for transparency and programme design. It is not a medical diagnosis and should not replace clinical interpretation.
